#  Mini Media Feed App

A lightweight and responsive React.js application that displays a curated media feed.

##  Live Demo  
[Click here to view the deployed app](https://react-mini-media.netlify.app/)

---

##  Features

- Fetches and displays media content 
- Clean and responsive card-based UI
- Dynamic rendering using React Hooks
- Error handling for API fetch failures

---

##  Tech Stack

**Frontend:**
- React.js  
- HTML, CSS, JavaScript  
- Axios (for API calls)  

**Development Tools:**
- VS Code  
- Git & GitHub  
- Netlify / Render (for deployment)
